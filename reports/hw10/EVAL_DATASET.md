# Homework 10 judge-validation dataset

`eval_cases.json` and `human_labels.csv` are the frozen validation inputs for
Part 3. The 20 drafts are representative Writer outputs for the community
sports fixture domain. The labels were assigned manually on the required 1–5
helpfulness scale before any judge scores were generated.

Judge scores must be written to a separate raw-results file so these reference
inputs remain unchanged.
