# Community Sports League Application Instructions

- Project: maintain the Community Sports League API and its memory features.
- Technology: use Python, FastAPI, MongoDB, and the local Ollama model adapter already in the project.
- Coding: keep functions small, use clear names, and add concise comments only where needed.
- Testing: verify behavior with repeatable commands and keep raw test output in the homework report folders.
- Data safety: do not delete or overwrite user data unless the action is explicitly requested.
- Memory: preserve stated dates, times, venues, and preferences; report conflicts instead of silently changing them.

## Code Review Instructions

When reviewing code:

- Respond using bullet points only.
- Identify correctness problems, security or reliability concerns, and specific improvements.
- Keep the review concise.
